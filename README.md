# Calculadora Modular en Python 🐍

Este es un proyecto sencillo de una calculadora básica desarrollada en Python, separando la lógica matemática de la interfaz de usuario mediante módulos.

## 🚀 Estructura del Proyecto

* `Operaciones.py`: Módulo que contiene las funciones matemáticas (`sumar`, `restar`, `multiplicar`, `dividir`).
* `main.py`: Archivo principal que gestiona la entrada de datos del usuario y muestra los resultados.
